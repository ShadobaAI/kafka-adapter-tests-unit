## Способ вызова: напрямую по умолчанию, ФЗ только по необходимости

Уточнение по согласованию с пользователем: принадлежность метода к обработчику фоновой операции и суффикс ВПотоке сами по себе не требуют запуска теста в ФЗ. Логику обработчиков проверять прямым вызовом оригинальных методов в сеансе теста. Реальные ФЗ нужны только для поведения, которое явно зависит от платформенного задания или взаимодействия отдельных сеансов.

| Проверяемое поведение | Способ проверки |
|---|---|
| Выборки, сериализация, отправка, загрузка, десериализация, статусы, ошибки, распределение, указатели, очистка | Прямой вызов оригинального метода с подготовленными данными и допустимыми подменами внешних зависимостей |
| Цикл рабочего обработчика, блокировка, пустая очередь, таймаут | Прямой вызов с конечной последовательностью внешних состояний и проверенной границей времени/ожидания; наличие цикла не требует ФЗ |
| ЗапуститьФЗ, ЗапуститьПоток, поиск активного задания, отмена, получение текущего ФЗ | Настоящее ФЗ с небольшим тестовым обработчиком; оригинальный механизм запуска и управления заданиями сохраняется |
| Межсеансовая видимость, конкуренция, порядок завершения реальных заданий | Отдельный сценарий с реальными ФЗ только для соответствующего межсеансового контракта |
