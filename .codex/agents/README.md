Здесь хранятся в Git копии AGENTS.md для соседних EDT-проектов:

| Файл в этом репозитории | Рабочее расположение относительно корня репозитория unit |
|---|---|

| `AGENTS.examples.md` | `../examples/AGENTS.md` |

Инструкции самого репозитория unit находятся в корневом `AGENTS.md`.
